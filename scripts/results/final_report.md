---

## 关键发现

1. **轻量级网络 (MobileNetV2)**: TFLite 和 MNN 表现最好，ncnn 紧随其后
2. **重量级网络 (ResNet50)**: TVM 表现最优，比 ncnn 快约 39%
3. **初始化速度**: TVM (2-3ms) << MNN (40-45ms) < ncnn < TFLite < ONNX Runtime < TNN
4. **延迟稳定性**: MNN 和 TNN 的标准差最小 (<0.1ms)，最稳定
